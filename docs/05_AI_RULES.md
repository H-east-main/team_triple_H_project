# AI 개발 규칙

1. 기존 디렉터리 구조를 변경하지 않는다.
2. 요청받지 않은 파일은 수정하지 않는다.
3. API URL과 필드명을 임의로 변경하지 않는다.
4. 새로운 라이브러리를 설치하지 않는다.
5. 기존 기능을 삭제하거나 대체하지 않는다.
6. 코드를 작성하기 전에 수정 대상 파일을 먼저 제시한다.
7. 전체 파일을 다시 작성하지 말고 필요한 부분만 수정한다.
8. 불명확한 내용은 임의 판단하지 않고 질문한다.
9. 작업 완료 후 변경 파일과 테스트 방법을 설명한다.
10. 한 번의 작업에서는 하나의 기능만 구현한다.
